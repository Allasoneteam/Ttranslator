## Первостепенное (после версии 1.0)

1. **Оценка точности вариантов («% соответствия»).** Исходная идея проекта: варианты с оценкой близости к смыслу оригинала, лучший — первым.
   - Первый шаг: обратный перевод каждого варианта и сравнение с исходным текстом → значок «≈ 85 %», пометка лучшего варианта.
   - Второй шаг: оценка самой моделью (0–100 и главная неточность) для сомнительных случаев.
   - Дальше: отдельная небольшая модель оценки качества перевода (проверив её лицензию).
   - Оценка — ориентир, а не истина; так и показывать. Объём: средний.
2. **Длинные тексты.** Режим «по абзацам» без лимита 1000 знаков: деление на абзацы и предложения, перевод по очереди с общим контекстом и словарём, прогресс, копирование целиком. Объём: средний.
3. **Сравнение моделей одной кнопкой.** Тест подряд на нескольких скачанных моделях (с автоматическим переключением) и одна сводная таблица: скорость, chrF, переводы рядом. Объём: небольшой–средний.
4. **Словарь: удобство и контроль.**
   - «В словарь» прямо из карточки: выделить термин в тексте и в варианте.
   - Проверка, использовала ли модель термин из словаря: подсветка в варианте, предупреждение, если нет.
   - По желанию: предпочтительные термины и для правки на том же языке.
   - Объём: небольшой.
5. **История переводов.** Последние запросы с поиском, повтор одним щелчком. Объём: небольшой.
6. **Больше тестовых фраз.** Фразы на немецком и других языках, фразы с терминами словаря, наборы по темам (в основном — фразы автора). Объём: небольшой.
7. **«Случайно» и ↔: доработки по итогам проверки.** Например, «Случайно и сразу перевести»; ↔ с подстановкой первого перевода в поле текста.

## Перспективное

1. **Видеокарта.** Сборка движка с Vulkan (AMD, NVIDIA, Intel) и автоматический выбор: модели E4B и Q8_0 станут быстрыми.
2. **Текст с изображений.** Gemma 4 понимает изображения (в llama.cpp для этого нужен дополнительный файл mmproj): скриншот страницы PDF или подписи к рисунку → текст и перевод.
3. **Документы целиком.** DOCX, файлы LaTeX, PDF — с сохранением разметки.
4. **Для других пользователей.**
   - Выпуски на GitHub с готовым архивом.
   - Подпись исполняемого файла, чтобы не было предупреждения SmartScreen.
   - Проверка обновлений.
   - Лицензии движка и моделей указаны в «О программе»; для каждой новой модели — проверить лицензию и дописать.
5. **Новые модели по мере выхода.** Через каталог, с проверкой кнопкой «Тест».
6. **Общие словари для группы.** Общая папка или репозиторий; импорт стандартных терминологических форматов (TBX).
