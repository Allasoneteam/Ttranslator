# Phrases for the “Test” button · Фразы для кнопки «Тест».
# A pair is two lines in a row, “XX: …” in two different languages, where XX is the code of the language:
# EN, RU, DE, FR, ES, EL, ZH, LA, SV. Pairs are separated by an empty line; lines starting with # are skipped.
# You can add your own pairs. Each pair is translated both ways in the neutral and the casual style, and each
# phrase is also corrected in its own language. Phrases with LaTeX formulas are in the “Settings” section of
# ui/index.html (MATH_TESTS).
# Пара — две строки подряд «XX: …» на двух разных языках (XX — код языка: EN, RU, DE, FR, ES, EL, ZH, LA, SV);
# пары разделяются пустой строкой, строки с # в начале пропускаются. Можно дописывать свои пары. Каждая пара
# переводится в обе стороны в нейтральном и разговорном стиле, и каждая фраза исправляется на своём языке.
