# Задания для облачных сессий Claude

Каждый файл здесь — самостоятельное задание. Автор запускает обычную облачную сессию (claude.ai/code) на этом репозитории и пишет ей одну фразу: «Прочитай CLAUDE.md и .claude/tasks/<файл> и выполни задание». Сессия работает в своей ветке; координатор — чат проекта автора — проверяет её работу и сливает в `dev`.

| Файл | Что | Выдано |
| --- | --- | --- |
| `macos-1.1.md` | Ttranslator 1.1 для macOS: программа запуска, окно, Ttranslator.app, CI на Mac, тестовые архивы | 01.11.2026 |
| `android-feasibility.md` | Android: можно ли и как; пробный APK; кратко — iPadOS | 01.11.2026 |

Отчёты сессий — в описании их черновиков PR (или в файле, который называет задание). Инструменты для заданий — в `.claude/tools/`.
